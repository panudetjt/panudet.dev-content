## ความคิดที่ไม่ได้เขียน คือความคิดที่หายไป

ผมเริ่มจากปัญหาง่าย ๆ: อ่านอะไรเสร็จแล้วลืม. จดไว้ในสมุดก็หากลับมาไม่เจอ. พอมีหลายโปรเจกต์และหลายหัวข้อที่ต้องคิดพร้อมกัน ความจำก็กลายเป็นคอขวด.

Second brain สำหรับผมจึงไม่ใช่ระบบจัดระเบียบที่สมบูรณ์แบบ แต่เป็น**ที่พักชั่วคราวของความคิด** ที่มีทางกลับมาเสมอ:

- note หนึ่งใบควรตอบได้ว่ามันเกี่ยวกับอะไร
- ควรมี link ไปหา note อื่นที่เกี่ยวข้อง
- ควรอยู่ใน PARA role เดียว และ zettel stage เดียว

> เขียนให้คนอื่นอ่าน คือการเขียนให้ตัวเองอ่านอีกรอบ ในวันที่ลืมไปแล้วว่าคิดอะไรอยู่

## ทำไมต้อง public

การเผยแพร่ทำให้ความคิดมีน้ำหนัก. ถ้าคิดไม่ออกว่าจะอธิบายให้คนอื่นเข้าใจยังไง แปลว่ายังไม่เข้าใจมันจริง. แต่ละ note จึงถูกเขียนให้จบในตัวเอง และเชื่อมกับ note อื่นด้วย wikilink แบบนี้

[[why-static-first]] เป็นอีกตัวอย่างหนึ่งของการคิดเรื่องเดียวกันจากมุมวิศวกรรม.

## สิ่งที่ไม่ต้องสมบูรณ์

บาง note เป็นเพียง fleeting — เก็บไว้ก่อน แล้วค่อยกลับมา. บาง note เป็น literature — สรุปจากสิ่งที่อ่าน. มีเพียงไม่กี่ใบที่เป็น permanent และถูก link เข้ากับส่วนอื่นของสวน.

ระบบที่ดีคือระบบที่ยังใช้งานได้ในวันที่ไม่มีแรงจัดระเบียบ.
